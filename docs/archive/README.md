# Archived docs

These docs are kept for history only. They describe plans that were finished,
superseded or abandoned, and point-in-time reports from before the project's
2025–2026 pause. Paths and status claims in them are not maintained and are
often stale (for example, references to the deleted `backend/src` tree).

For current plans and status, see the [roadmap index](../roadmap/README.md), which
records why each doc here was archived.
