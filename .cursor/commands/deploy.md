# /deploy

Run `scripts/deploy/deploy.sh` to deploy EconGraph to the existing kind cluster
(`econ-graph` by default, using context `kind-econ-graph`). Build the application
images first; see [Build Docker Images](../../k8s/README.md#2-build-docker-images).

Ask Joe before you run it. Deploying needs his say-so; see [AGENTS.md](../../AGENTS.md).

```text
/deploy
```
